# Changelog

All notable changes to this template are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and
[Semantic Versioning](https://semver.org/).

## [1.0.0] — 2026-01-01

### Added

- Single-page café/restaurant landing page built with Next.js 16, React 19, TypeScript and
  Tailwind CSS 4.
- Typed, single-file content configuration (`lib/site.ts`) covering every string, price, link, hour
  and image.
- Sections: hero, trust strip, story with image collage and stats, filterable menu, gallery,
  testimonials, and a reservation/contact section.
- Working reservation form with server-side zod validation, inline and announced errors, honeypot,
  IP rate limiting, success state and optional webhook delivery.
- SEO: metadata templates, canonical URLs, `CafeOrCoffeeShop` JSON-LD, `sitemap.xml`, `robots.txt`,
  web manifest and a generated Open Graph image.
- Accessibility: skip link, semantic landmarks, focus-visible styling, keyboard and `Escape` support
  in the mobile menu, labelled form controls, and reduced-motion support.
- Legal pages: privacy policy and terms of use, with a review reminder.
- Commercial license template, README, contributing conventions and Prettier/ESLint/TypeScript
  configuration.
